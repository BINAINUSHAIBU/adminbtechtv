BTECH-TV Locked / Unlocked Channel Settings

Path: locked_channels/index.html

Features merged from the supplied ULTRA MAX channel-control dashboard:
- Super Admin login (demo password 1234)
- IPTV channels loaded from iptv-org channels/streams/logos APIs
- Free, Paid/Premium, Locked and Unlocked access states
- Per-channel Lock / Unlock / Paid controls
- Lock ALL, Unlock ALL, Paid ALL, Reset Access
- Search and access filters
- Channel access statistics
- Default access settings
- Require admin for locked channels
- Show/hide locked channels setting
- Package-access setting and minimum package
- LocalStorage persistence for access overrides and settings
- HLS player with autoplay/muted/playsinline

This is a static front-end control panel. For shared production administration across users/devices, connect the controls to a server-side database/API.
